  • Swatches change the glow colour (orange / blue)
  • Front / back flip on the stage
  • Made-to-order timing shown before you add
  • Drawer, not a new page, for the bag

  • Tabs carry counts so you can see what needs doing
  • Publish / sign-ups are toggles, not checkboxes

Admin · Door

Built for a phone or tablet at the door. Camera on the left with a big green or orange result after each scan; the guest list on the right with live search and one-tap check-in. Medical flags stand out so coaches see them first.

  • Green = checked in, orange = already scanned / wrong event
  • Live counter: in / waiting / capacity
  • Manual check-in for people without a phone

Admin · Orders & stock

Orders and stock side by side, because fulfilling an order and checking what’s left usually happen together. Stock uses steppers; edited rows glow orange and a single Save bar appears. A toast confirms each action with Undo.

  • Filter chips with counts: To fulfil · Fulfilled · Refunded
  • Tracking note inline, fulfil in one click
  • Low-stock warning per size
